# Nexcent Landing Page

A responsive landing page created as my first HTML/CSS project during my Frontend Developer internship.

## About the Project

This project is a recreation of the Nexcent landing page design. It includes a responsive navigation bar, hero section, client logos, community cards, statistics, and other landing-page sections.

## Features

- Responsive landing page design
- Navigation bar with menu links
- Hero section with call-to-action button
- Client/logo section
- Community and membership cards
- Statistics section
- Responsive layout for desktop, tablet, and mobile screens
- Font Awesome icons
- Image assets used from the project `images` folder

## Technologies Used

- HTML5
- CSS3
- Font Awesome
